Ziggy's Driver — installable PWA

Files:
- index.html
- manifest.webmanifest
- sw.js
- icons/

What works now:
- Today / Upcoming / Completed tabs
- Driver #1 workflow
- Ready -> Picked Up -> Delivered
- Google Maps navigation links
- Local persistence on the phone/browser
- Installable PWA shell
- Offline app shell

Important:
This package is the standalone app front-end. Orders currently live locally on the device.
To make customer website orders appear automatically, connect this app to the production
order backend/database and authentication layer before using it as the final production system.
